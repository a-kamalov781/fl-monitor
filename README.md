# fl-monitor

Telegram-бот, который читает публичные RSS-ленты FL.ru, отбирает подходящие заказы и готовит черновик отклика.
Откликаетесь вы сами: логина на FL.ru и действий на сайте у бота нет.

## Что делает

- Раз в 3 минуты читает ленты: по одной, с паузой 2 секунды. На ответы 429 и 503 делает перерыв.
- Сохраняет все заказы в SQLite. Каждый заказ приходит один раз, повторы отсекаются по id.
- Отбирает по ключевым словам, минус-словам и бюджету от 3000 ₽. Заказ без бюджета проходит с пометкой «по договорённости».
- Назначает категорию (booking, ai, integration, parser, other) и оценку от 1 до 5.
- Присылает карточку с черновиком и кнопками: открыть заказ, другой вариант, скрыть, откликнулся.
- С 01:00 до 08:00 МСК копит заказы, утром присылает сводку.
- `/stats`, `/top`, `/export` показывают, что заказывают на рынке и как быстро вы откликаетесь.

## Ленты

| Адрес | Раздел |
|---|---|
| `https://www.fl.ru/rss/all.xml` | вся биржа |
| `https://www.fl.ru/rss/all.xml?category=5` | Программирование, включая «Разработка Чат-ботов» |
| `https://www.fl.ru/rss/all.xml?subcategory=37&category=5` | Программирование / Веб-программирование |
| `https://www.fl.ru/rss/all.xml?category=34` | Мессенджеры |
| `https://www.fl.ru/rss/all.xml?category=41` | Автоматизация бизнеса |
| `https://www.fl.ru/rss/all.xml?category=31` | AI |

Другой набор задаётся в `FEED_URLS`.

## Что учитывать

- RSS часто обрезает описание примерно до 170 знаков, поэтому пунктов в черновике иногда меньше двух из описания.
  Тогда в черновик идёт заголовок. Ключевые слова ищутся в том же обрезанном тексте. Чтобы не терять заказы,
  профильные разделы вроде «Разработка Чат-ботов» и «Боты для бизнеса» тоже считаются совпадением.
- Заказ без пометки «для всех» на FL.ru может требовать PRO-аккаунт. Пометка показывается в карточке.
- Заказы вроде «ИИ-видео» проходят по слову «ИИ», но получают оценку 1: это работа монтажёра.
- Цена для категории other в задании не указана. В шаблоне стоит 9 900 ₽.
- Время реакции считается от момента, когда бот показал заказ.
- При первом запуске в чат приходят только 3 самых свежих подходящих заказа. Остальные заказы из лент идут в статистику.

## Запуск

```bash
cp .env.example .env   # заполнить BOT_TOKEN и ADMIN_ID
docker compose up -d --build
```

После запуска нажмите `/start` в боте: Telegram не даёт боту написать первым.

## Черновики через LLM

Если заданы `LLM_BASE_URL`, `LLM_API_KEY` и `LLM_MODEL` (OpenAI-совместимый API), черновик пишет модель.
При ошибке или ответе длиннее 600 знаков используется шаблон.

## Разработка

```bash
python -m venv .venv
.venv/Scripts/python -m pip install -r requirements-dev.txt
.venv/Scripts/python -m pytest
```

Тесты работают без сети: RSS отдаёт `httpx.MockTransport`, запросы к Telegram складываются в список.
